# Govt. Rabia Basri Graduate College - Landing Page

A modern, responsive, mobile-first frontend landing page crafted from the Figma prototype for **Govt. Rabia Basri Graduate College, Walton Road, Lahore**.

## 🚀 Built With
- **HTML5** semantic markup & accessible ARIA standards
- **CSS3** with custom design variables, responsive grid, animations, and typography tokens
- **Bootstrap 5.3** framework (via official CDN)
- **Bootstrap Icons** & **FontAwesome 6** (via official CDN)
- **Google Fonts** (*Plus Jakarta Sans* & *Playfair Display*)
- **Vanilla JavaScript** (Zero dependencies, pure ES6+)

## 🌟 Sections Included
1. **Top Bar**: Official College Seal, college title, phone/email contact information, and "Apply Online" badge button.
2. **Main Sticky Navigation**: Dynamic navbar with scroll transition and anchor navigation links.
3. **Hero Section**: High-resolution college campus background, bold headline (*"Education with Purpose, Future with Promise"*), CTA buttons, and slide dots.
4. **Principal's Message**: Formatted executive profile of the Principal with quote highlight and collapsible "Read More" functionality.
5. **Explore Disciplines / Admissions**: Interactive tabs switching between **BS 4-Year Admissions** and **Intermediate Admissions (FSc, ICS, I.Com, FA)** with custom color badges.
6. **Key Statistics Counter Bar**: Animated counter numbers on scroll (2,000+ Enrolled, 3,500+ Active Students, 15,000+ Alumni, 120+ Faculty & Staff).
7. **Latest News & Notifications**: Event notification cards with date badges, image previews, and circular links.
8. **Campus Life & Facilities**: 2x2 photo collage of laboratory, library, IT center, and auditorium with interactive facility description list.
9. **Student Services Deck**: Interactive cards for Admissions, Scholarships, Examination Cell, Clubs, Health Center, and Career Counseling.
10. **Events Photo Gallery**: Responsive image gallery with interactive lightbox modal viewer.
11. **Admissions Inquiry Modal**: Functional Bootstrap modal dialog for prospective students to submit inquiries.
12. **Comprehensive Footer**: College description, academic programs list, quick navigation links, address, contact hours, and social media handles.

## 💻 How to View & Run
Simply double-click or open `index.html` in any web browser (Google Chrome, Microsoft Edge, Firefox, Safari). No build tools, node server, or bundlers required!
